# Tesla

Este é um projeto de página inicial para a Tesla, criado com HTML, CSS e imagens.

## Descrição

A página inicial é uma réplica da página oficial da Tesla, com uma estrutura simples e responsiva. Ela inclui uma navbar com links para diferentes seções da página, uma seção principal com informações sobre o modelo 3 e uma seção de botões para ordenar ou fazer um teste drive.

## Tecnologias utilizadas

* HTML5
* CSS3
* Imagens

## Arquivos incluídos

* `index.html`: arquivo principal da página
* `style.css`: arquivo de estilos CSS
* `elements.css`: arquivo de estilos CSS adicional
* `assets/`: pasta com imagens utilizadas na página

## Como utilizar

1. Clone o repositório para o seu computador
2. Abra o arquivo `index.html` em um navegador
3. Explore a página e veja como ela funciona
